# zerotwo

Танец Zero Two из символов прямо в терминале. Как `sl`, только вместо паровозика 02, и танцует по кругу, пока не нажмёшь `Ctrl+C`.

```
                         -.:: -:--:
                        = ..-*%%*+#%+::  ---..
                        -...:#####*#%+:::....:
                        =..:-%*+%**###:*--..--
                         =.:.*%#@#+#%**+=:.::
                         =.:.-#%@@@@@+#++.:=
                         -+..:+%%*%%*==*=-=
                        :#*..:.*%#*+*++-.+==+-
                       .#%#....:=**++++--   -+-
                       +%#%+...-#*****=*#
                      :%%%%%-..-=-=.#-+--==
                      #%%%%%#:-+--===----+-
                     -%%%%%%%+-====--=---=:
                     #%%%%%%%%=======--=-.
                    :%%##%##%%+=--= ----=
```

Нужен только `python3` (в Ubuntu и большинстве дистрибутивов уже есть). Никаких библиотек, ffmpeg и интернета: все 90 кадров зашиты в один файл.

## Установка

Одной командой:

```
mkdir -p ~/.local/bin && curl -fsSL https://raw.githubusercontent.com/Yozmor/zerotwo/main/zerotwo -o ~/.local/bin/zerotwo && chmod +x ~/.local/bin/zerotwo
```

Или через git:

```
git clone https://github.com/Yozmor/zerotwo.git
cd zerotwo
sh install.sh
```

Если после установки пишет «команда не найдена», перезапусти терминал.

## Запуск

```
zerotwo
```

Выход: `Ctrl+C`.

Чем мельче шрифт и больше окно, тем детальнее картинка: разверни терминал на весь экран и уменьши шрифт (`Ctrl` + `-`). Размер окна можно менять прямо во время танца.

## Удаление

```
rm ~/.local/bin/zerotwo
```

## Как это сделано

1. Видео разрезано на кадры, из них выбраны 90 подряд, где последний почти совпадает с первым, поэтому петля идёт без рывка.
2. Из каждого кадра вырезана основная фигура, двойники-контуры по бокам убраны.
3. Яркость растянута и подчёркнуты линии, чтобы картинка была контрастной.
4. При запуске каждый кадр ужимается под размер терминала, и каждой ячейке подбирается символ по яркости из шкалы ` .:-=+*#%@`.
